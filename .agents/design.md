Visual Aesthetic Philosophy & Brand IdentityTheme Selection: ELITE DIST Enterprise Blue Theme — inspired by the official ELITE DIST cyan-to-deep-blue ribbon logo:   Light Mode (Blue & White): Crisp Pure White and Cool Slate surfaces paired with authoritative Ocean and Royal Blue primary accents.Dark Mode (Blue & Black): Deep Obsidian/Black and Slate-950 surfaces paired with luminous Cyan-Blue and Electric Blue accents.Strict Zero-Purple & Anti-AI-Slop Mandate (Unslop + Stageshow Doctrine):Zero Purple Rule: Purple, violet, indigo-purple, or magenta hues (#8b5cf6, #a855f7, #6366f1) are strictly banned across every button, badge, chart, gradient, and border.   Zero AI Visual Slop: Never use glowing neon borders, floating 3D blobs, stock AI sparkle icons, or oversized muted icon boxes.   Stageshow Visual Restraint: Avoid the five classic UI failures (Too much, Wireframe, Boxed, Flat, and Bland). Every screen must establish a clear visual hierarchy through quiet neutral surfaces, crisp 1px structural borders, and purposeful blue focal points on primary actions and active states.Unslop Copywriting Standard: Eliminate chatbot residue, throat-clearing intros, and vague jargon from all UI microcopy, empty states, modals, and tooltips. Every label, button, and helper message must be direct, human-crafted, and immediately understandable by a beginner or child.2. App-Shell Architecture & Viewport-Locked Workspace (AppShell.jsx)Every role portal and back-office module renders inside the unified AppShell.jsx layout so the entire ERP operates as a single, cohesive product:   Viewport-Locked Desktop Architecture (Zero Unnecessary Page Scroll):On desktop screens (>= 1024px), the outer shell locks to the dynamic viewport height (100dvh, overflow-hidden) so the browser window itself never develops an ugly double scrollbar.Inside the main workspace, the Topbar (h-14), Page Header & Filter Toolbar, and KPI strip remain fixed in view, while only the inner table container or split-panel body scrolls vertically when needed (paired with scrollability affordance shadows and server-side pagination).Collapsible Left Sidebar (Sidebar.jsx, Desktop & Mobile):Brand Header: Displays the official ELITE DIST logo, agency title, active Role Badge (Super Admin, Booker, Salesman, POS, Storekeeper, Accountant), and a sidebar toggle/close button active on both desktop and mobile.   Strict Role Navigation Isolation: Each logged-in role sees strictly its own authorized navigation groups (Inventory & Stock, CRM & Beats, Order & Sales, Master Rules & Templates, Pending Tasks, Field Portals, HRM, ERP Accounts, Reports & Dashboards).   Collapsible Section Groups: Navigation groups collapse and expand smoothly to intrinsic height, persisting state in localStorage (elitedist_nav_groups).   Coming Soon Badges: Any planned phase or unbuilt route displays a subtle "Soon" pill badge and triggers the global <ComingSoonModal/> instead of leading to a dead route.   Desktop & Mobile Drawer Behavior: On desktop (>= 1024px), toggling the sidebar slides it off-canvas and expands the main workspace to full width (localStorage key elitedist_sidebar_collapsed), firing a window resize event after 220ms so charts and tables reflow cleanly. On mobile (< 1024px), it operates as an off-canvas slide-over drawer with light-dismiss backdrop and Esc key support.   Sticky Topbar (Topbar.jsx):Left: Sidebar toggle button, hierarchical Breadcrumb trail, and active module title.   Right: Global Quick Search (Ctrl+K / Cmd+K with IME-safe Enter handling), Quick Action Launcher (+ Order, + Movement, POS, Recovery), Real-Time Notification Bell dropdown with unread badge, and the Light/Dark Theme Toggle switch.   Full-Width Fluid Workspace (No Boxed Containers):Never trap ERP screens inside narrow centered containers (max-w-7xl mx-auto). Every dashboard, order builder, and stock table spans the full available width beside the sidebar with min-w-0 protection on all flex/grid children to prevent horizontal overflow.   4. Strict Z-Index & Top-Layer Overlay Hierarchy (Zero Broken Overlays)To guarantee dropdowns, sticky table columns, drawers, and modals never clip or collide:   z-10: Sticky table headers (thead), sticky action columns, and inline card badges.   z-20: Sticky Topbar (Topbar.jsx) and bottom pagination bars.   z-30: Fixed Desktop Sidebar (Sidebar.jsx).   z-40: Mobile Off-Canvas Sidebar Backdrop, Topbar Notification Flyout, and Viewport-Aware Action Dropdowns (which automatically flip axis near screen edges so menus never clip inside tables).   z-50: Global Modal & Drawer Layer (ConfirmModal, FormModal, PrintPreviewModal, TouchKeypadModal, ComingSoonModal) with background scroll locked (overflow-hidden on body) and light-dismiss / Esc key support.   z-60: Global Stacked Toast Notifications (ToastContainer.jsx) in the bottom-right corner.   5. Mandatory Tabular Numerals (tabular-nums):Every price, quantity (Carton : Pcs), discount percentage, weight, outstanding balance, and KPI counter must enforce font-variant-numeric: tabular-nums so numbers align vertically down every column and never jitter during live calculations.   Text Wrapping & Overflow Discipline:Apply text-wrap: balance on page titles, modal headers, and empty-state headings.   Apply single-line truncation (truncate with native title tooltip on hover) on long customer shop names, street/pehchan remarks, and sidebar items so a long string never breaks row height.   Respect OS Accessibility & Motion Preferences:Use rem-based fluid typography and honor @media (prefers-reduced-motion: reduce) across all transitions.6. Data Tables, Pagination, Card Views & Mobile Responsiveness (SmartDataTable.jsx)Based on the 285-page wireframe specifications, every data listing across Inventory, Stock, CRM, Orders, Sales, Movements, and Accounts must support:   Dual Data Style Switcher (Table List vs. Card View) & Column Customizer:Every master listing toolbar includes a Data Style toggle (Table List / Card View) and a Show/Reset Columns popover allowing the operator to toggle individual columns on or off.   Mandatory Server-Side Pagination & Viewport Fit:Dashboard summary tables default to 5 rows per page; full master data tables default to 10 or 15 rows per page (configurable via .env and page-size selector) so tables fit cleanly inside the desktop viewport without page scrollbars.   Synchronized <PaginationBar/> displays Showing X–Y of Z records, page numbers, and Previous/Next controls.   Mobile-First Responsive Transformation (< 768px):Never squeeze a 10-column ERP table onto a mobile screen.   On viewports < 768px, <SmartDataTable/> automatically hides the desktop tabular grid (hidden md:block) and renders Mobile Stacked Cards (md:hidden) displaying the primary title, SKU/Code badge, key financial/stock pairs (Carton/Pcs, Rate, Status), and touch-friendly action buttons (min-h-[44px]).   Field Portal Touch Ergonomics (Booker, Salesman & Stock Count):Mobile portals (/portal/booker, /portal/salesman, /portal/pos, and Stock Adjustment Count) provide category/brand filter pills, 1-tap customer/product cards, and the global <TouchKeypadModal/> (0–9, +, -, Clear, OK) so field staff can punch quantities and physical counts with one thumb.   7. Forms, 2-Level Invoice Workbench & Print Preview StandardsInteraction-After Validation (Zero Preemptive Red Errors):Following Chrome Modern Web Guidance, form fields must never show red error borders on initial render or while the user is still typing. Validation feedback appears only after blur/interaction (:user-invalid or touched state) and synchronizes aria-invalid with screen readers.   Auto-Fit & Multi-Row Sub-Tables:Complex forms (Add Company, Add Brand, Add Warehouse, Add Customer) use clean tabbed or stepped sections with inline sub-tables for adding multiple Contacts (WhatsApp/Phone), Social Media Links, and Bank/EasyPaisa/JazzCash Accounts without cluttering the screen.   2-Level Invoice & Order Workbench (/orders/create):Designed as a split, viewport-fitted workbench:Top Bar: Customer selector with instant Credit Limit, Outstanding Balance, and Warning badges (Pending Order, Blocked, Credit Not Allowed).   Center Grid (Level 1 — Item Level): Fast inline product entry with Unit switcher (Carton, Dozen, Piece), live stock indicator, reverse Sale Rate calculator (auto-calculating Discount % or Flat Discount when custom Sale Rate is typed), Charge selector, and auto-inserted Free Scheme rows.   Bottom/Side Dock (Level 2 — Grand Level): Live rolling totals (Total Items, Total QTY, Total Weight KG, Total Volume, Gross Amount, Item Discounts, Grand Discount, Grand Charges, Tax, and Net Payable Amount) with 1-click toggles for Grand Rules and Print Layout styles (Chillan + Finance, Detailed Landscape, Advance Invoice, POS Receipt).   Full-Size Print & Share Modal (PrintPreviewModal.jsx):Every report, invoice, dispatch sheet, salesman sheet, and recovery sheet opens in a clean A4/Thermal print preview modal supporting customizable Headers/Footers (English/Urdu, Signatures, Notes) and 1-click Print, Export PDF, Export Excel/CSV, and Share to WhatsApp.   8. AI Agent Anti-Loop, State Stability & Performance GuardrailsTo prevent AI coding agents from introducing infinite React re-render loops, memory leaks, layout thrashing, or broken UI states, every component must obey these 8 engineering guardrails:Zero useEffect Fetch Loops: Never place non-primitive objects, inline arrays, or un-memoized functions inside useEffect dependency arrays that trigger state updates or API calls. Use TanStack Query (useQuery / useMutation) with stable primitive query keys (['products', distributorId, page, limit, debouncedSearch, filters]) for all data fetching.Derived Calculations Over Effect Syncing: In the 2-Level Invoice Engine, Dimension/Volume Calculator ($W \times L \times H$), and Packing Weight Calculator, compute totals synchronously during render (useMemo) or inside event handlers — never chain multiple useEffect hooks that watch state A to setState B.Debounced Search & Filter Inputs: All search inputs (FilterToolbar.jsx) must debounce API requests by 300ms and reset pagination to page = 1 inside the input change handler, never inside an uncontrolled effect loop.Cloudinary Upload Isolation: Image selection in <ImageDropzone/> must preview locally via URL.createObjectURL (revoked on cleanup) and upload to Cloudinary only on explicit user action or form submission with a locked loading spinner (isSubmitting) to prevent duplicate uploads.Chart & Resize Observer Stability: Wrap all charts in a fixed-height container (h-48 to h-56, min-w-0) so responsive chart observers never trigger infinite height-expansion loops.Modal & Drawer Focus / Scroll Lock Cleanup: Global modals must use a single centralized controller (ShellContext) that cleanly restores document.body.style.overflow on unmount or route change so the page never gets permanently frozen after closing a modal.Break Up Long Tasks & Defer Offscreen Work: Large Excel/CSV exports and multi-invoice batch print previews must yield to the main thread (requestAnimationFrame / async chunking) to keep Interaction to Next Paint (INP) under 200ms.Zero Dead Buttons & Custom 404 Safety Net: Every button, icon action, and sidebar link must either execute a complete working action or open <ComingSoonModal/>. Unrecognized URLs must always render the theme-aware <NotFound404/> screen.
